# FreelanceHub

A full stack freelancing platform built using React, Flask and MySQL.

## Features
- User authentication
- Employer & Employee dashboards
- Project posting
- Bidding system
- Task assignment
- Chat system
- Payment tracking
- Learning resources
- OTP verification

## Tech Stack
Frontend:
- React.js
- CSS

Backend:
- Flask
- MySQL

## Installation

### Frontend
cd frontend
npm install
npm start

### Backend
cd backend
pip install -r requirements.txt
python app.py
